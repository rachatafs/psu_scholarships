Database Tables (5 ตาราง)

master_meter_type

ประเภทมิเตอร์ + ราคาต่อหน่วย

meter_type_id PK
type_name "water", "electricity"
unit_price 15.00, 4.50

master_meter

มิเตอร์แต่ละตัว (เลขมิเตอร์, ตำแหน่ง)

meter_id PK
meter_name "W-001", "E-001"
meter_type_id FK → master_meter_type
dock_id FK → master_dock

booking_meter

ผูกมิเตอร์กับ booking + ค่าที่อ่าน

booking_meter_id PK
ref_booking_id FK → booking
meter_id FK → master_meter
prev_reading 100.00
curr_reading 150.00
raw_usage 50.00 (auto)
unit_price 15.00
total_amount 750.00 (auto)

meter_read_transaction

ประวัติการจดค่ามิเตอร์

trans_id PK
meter_id FK → master_meter
booking_id FK → booking
read_date 2026-07-01
read_value 150.00
read_type "initial", "final"

utility_billing

Billing records (รอออกบิล)

billing_id PK
booking_meter_id FK → booking_meter
billing_period "2026-07"
usage 50.00
unit_price 15.00
total_amount 750.00
status "Draft" → "Approved"
invoice_id FK → invoice_head

Relations

master_meter_type

1:N → master_meter

master_meter

1:N → booking_meter

1:N → meter_read_transaction

booking_meter

1:N → utility_billing

utility_billing

N:1 → invoice_head

Use Case Flows (3 scenarios)

Flow 1: ลูกค้าเช็คอิน → ผูกมิเตอร์

1

ลูกค้าเช็คอินที่ท่าเรือ

สร้าง booking ในระบบ

2

เลือกมิเตอร์ที่จะใช้

ดูรายการมิเตอร์ว่างจาก GET /api/meters

3

ผูกมิเตอร์กับ booking

POST /api/meters/bookings/:bookingId 

{
  "meterId": 1,
  "connectedAt": "2026-07-01T10:00:00Z"
}
4

ระบบบันทึกค่ามิเตอร์เริ่มต้น

ตาราง booking_meter สร้างแถวใหม่

booking_meter_id: 1
ref_booking_id: 100
meter_id: 1
prev_reading: 100.00
curr_reading: 100.00
status: "active"

Flow 2: สิ้นเดือน → คำนวณค่าน้ำไฟ + ออกบิล

1

พนักงานจดค่ามิเตอร์

POST /api/meters/readings 

{
  "meterId": 1,
  "bookingId": 100,
  "readValue": 150.00,
  "readType": "monthly"
}
2

ดู Preview ค่าน้ำไฟรายเดือน

GET /api/utility-billing/preview?fromDate=2026-07-01&toDate=2026-07-31 

[
  {
    "bookingNo": "BK-2026-001",
    "customerName": "เรือยอทช์ A",
    "meterName": "W-001",
    "meterType": "water",
    "prevReading": 100.00,
    "currReading": 150.00,
    "usage": 50.00,
    "unitPrice": 15.00,
    "totalAmount": 750.00
  }
]
3

Bulk Generate Invoices

POST /api/utility-billing/generate 

{
  "billingIds": [1, 2, 3]
}

ระบบสร้าง invoice หลายใบใน transaction เดียว

4

ระบบอัปเดตสถานะ

utility_billing.status: "Draft" → "Approved"

utility_billing.invoice_id: ถูกตั้งค่า

Flow 3: ลูกค้าเช็คเอาท์ → ปลดมิเตอร์

1

จดค่ามิเตอร์ครั้งสุดท้าย

POST /api/meters/readings 

{
  "meterId": 1,
  "bookingId": 100,
  "readValue": 200.00,
  "readType": "final"
}
2

ปลดมิเตอร์จาก booking

POST /api/meters/bookings/:bookingId/:meterId/disconnect

3

ระบบอัปเดต booking_meter

curr_reading: 200.00

status: "completed"

disconnected_at: 2026-07-31

4

คำนวณยอดสุดท้าย

POST /api/utility-billing/calculate 

{
  "bookingMeterId": 1,
  "usage": 100.00,
  "unitPrice": 15.00,
  "totalAmount": 1500.00
}
